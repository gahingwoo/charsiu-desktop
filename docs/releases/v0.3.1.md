Charsiu Desktop 0.3.1 finds the charsiu that the RK3576 tools install, so a Windows put on the board by Maskrom Studio can chat on the NPU with nothing else installed.

**Changes**

- On Windows the app looks for charsiu in `%LOCALAPPDATA%\Programs\charsiu` (charsiu-install.ps1), then in `%ProgramFiles%\RK3576\npu` (the RK3576 tools), then on PATH, where a `bin\charsiu.cmd` now counts as well. Before, only the first and a `charsiu.ps1` on PATH were found, and with the RK3576 tools alone the app said "charsiu is not installed".
- When the NPU admits only administrators, the notice has a "Restart as administrator" button (one UAC prompt; the app comes back elevated and gets the NPU). The text also says that a restart of Windows after installing the RK3576 tools or charsiu lets ordinary users use the NPU.
- charsiu's own warning that the NPU is for administrators only is read as such, not only the driver's error.
- Releases: the notes come from `docs/releases/`, and CI checks that SHA256SUMS.txt matches the digest GitHub serves for every file.

**Files**

- `charsiu-desktop_0.3.1_arm64-setup.exe`: Windows arm64 installer (per user)
- `charsiu-desktop_0.3.1_arm64.deb`: Debian/Ubuntu arm64
- `charsiu-desktop_0.3.1_aarch64.AppImage`: other Linux arm64, when it built
- `SHA256SUMS.txt`

The NPU variables are set by charsiu's front door from the user's config, as before. The Windows installer is not code-signed, so SmartScreen may warn. Not yet run on a board: see the board test in docs/development.md.
